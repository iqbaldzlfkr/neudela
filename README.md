# Neudela Design System Documentation Portal

Interactive documentation portal for the **Neudela Design System**, built using **React** and **Vite**.

## Features
- **Design Tokens**: Centralized custom properties for colors, typography, and spacing in `tokens.css`.
- **Interactive Component Library**: Live preview panels for core components (Button, Input, Badge, Alert, Card).
- **Multi-Language Snippets**: Real-time rendering and click-to-copy code blocks in **Vue 3 SFC**, **React**, and **HTML/CSS** formats.
- **Dark Mode**: Smooth visual transition for testing styles in dark and light interfaces.
- **Search Panel**: Instantly filter sidebar links by keyword.

## Running Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```
   Open the localhost URL displayed in the terminal to explore the portal.

3. **Production Build**:
   ```bash
   npm run build
   ```
